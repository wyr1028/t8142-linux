# M5 vs M4:PMGR 差异 —— **回答"几个月还是几年"**

**这是阶段 3 的核心问题**([ROADMAP](../ROADMAP.md))。现在有答案了。

---

## 1 方法

两边各有一份"电源域清单",而且**结构可比**:

| | 来源 | 形态 |
|---|---|---|
| **M4** | `linux-asahi` 的 `t8132-pmgr.dtsi` | 129 条 `power-controller@<偏移> { reg=<偏移 4>; label="<名字>"; }` |
| **M5** | 本机 ADT 的 pmgr `devices` 属性 | 387 条 48 字节记录(偏移 + 名字),由 [pmgr_devices.py](../tools/pmgr_devices.py) 解出 |

两边都提供 **(偏移, 名字)**,所以可以逐条对。

> M4 那份数据来自上游仓库,读取已获项目所有者明确授权(见 [PROVENANCE](PROVENANCE.md))。

---

## 2 结果

```
名字两边都有:        119 / 129   (92%)
★ 同名 + 同偏移:       8 / 129   ( 6%)   ← 可逐字复用
  同名 + 偏移不同:   111
  名字只有 M4 有:     10
  名字只有 M5 有:    268
```

**那 8 个偏移恰好相同的**(可原样照抄):

```
disp_cpu (0x10000)   gpio (0x120)      sep (0xc00)
venc_dma (0x8000)    venc_me0 (0x8018) venc_me1 (0x8020)
venc_pipe4 (0x8008)  venc_pipe5 (0x8010)
```

→ **视频编码器(venc)整块的 PMGR 布局原封不动搬过来了**,`gpio`/`sep`/`disp_cpu` 也是。

**偏移被打乱的例子**:

| 名字 | M4 | M5 |
|---|---|---|
| `aic` | 0x110 | 0x118 |
| `atc0_usb` | 0x0c0 | 0x0d0 |
| `apcie_sys_st` | 0x540 | 0x520 |
| `aes` | 0x2e8 | 0x3a0 |
| `ane_cpu` | 0xc008 | 0xc000 |
| `ane_mpm` | 0xc000 | 0xc010 |

注意 `ane_cpu` / `ane_mpm` —— **两个对调了**。这类"换了但换得有规律"的偏移,进一步说明是重新布线而不是随机。

---

## 3 结论:**月级,不是年级**

理由:

1. **结构可以复用**(标签名、`apple,always-on`、`#power-domain-cells`、节点形状)—— 92% 的名字对得上
2. **数值必须全部重算** —— 只有 6% 能照抄
3. **但重算是机械的,不是研究问题** —— M5 的偏移**我们已经从 ADT 里解出来了**

所以 `t8142-pmgr.dtsi` 的正确做法**不是手写**,而是:

```
M4 的 t8132-pmgr.dtsi   ←  提供结构(标签、属性、always-on 标记)
          ⋈  按名字 join
M5 的 devices blob      ←  提供偏移(reg)
          ↓
      t8142-pmgr.dtsi
```

**一个表连接,就能生成那个"大头"(M4 版 1125 行)。**

---

## 4 但有三条必须记住的限制

1. **这还不是可用的设备树。** 偏移是从 **macOS 过滤视图**里拿到的,虽然
   `387 × 48 = 18576` 精确吻合说明这段二进制**很可能是完整的**,但
   **必须在真机上验证**才能当依据用。

2. **387 条不能全塞进 DTS。** M4 的 ADT 上设备比 dtsi 多得多(m1n1 在 M4 Pro 上
   枚举 485 个,dtsi 只写了 129 条)—— 说明 **Asahi 做了筛选**,只写 Linux 需要的。
   我们需要搞清筛选口径,否则会写出一堆没人用的节点。

3. **名字对不上不等于设备没了。** 那 10 个 M4 独有(`dwi` `dpa0..4` `dpa_p`
   `ane_base` `ane_td` `nub_spi0`)可能在 M5 上改了名,也可能真的去掉了。
   同理 M5 那 268 个新的里,有一部分可能是 M4 设备的改名版。**需要人工对一遍。**
