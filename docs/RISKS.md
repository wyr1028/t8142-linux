# 实操风险(机器 / 数据 / 时间)

> 这份讲**机器和数据**的风险。
> **法律**风险在 [../LEGAL.md](../LEGAL.md),两码事,别混。

---

## 结论

**只有 M1(点亮 m1n1)会伤到机器。其余步骤要么完全可逆,要么只是浪费时间。**

| 阶段 | 风险 | 会伤机器吗 | 最坏结果 |
|---|---|---|---|
| M0 备第二台机器 | 极低 | 否 | 白跑一趟 |
| **M1 点亮 m1n1** | **高** | **是,唯一一步** | **丢数据 / macOS 起不来** |
| M2 采原始 ADT | 低 | 否 | 白跑 |
| M3 摸差异 | 低 | 否 | 得出"要几年" |
| M4 生成骨架 | 低 | 否 | 无 |
| M5 写设备树 | 低 | 否 | 编不过 |
| M6 引导内核 | 低 | 否 | 内核不启动 |
| M7 外设 | 低 | 否 | 无 |

**为什么 M2 之后都安全**:它们全在 m1n1 / 内核层面折腾,**不碰 macOS 的启动策略**。
引导失败最多是选错启动项、重启回 macOS。持久状态不变。

---

## M1 的四个子风险

### 1. 写错卷 → macOS 起不来(最实际)

`kmutil configure-boot -v <卷>` 如果指到 macOS 自己的卷上,可能让它无法启动。

**缓解**:动手前把"我要装到哪个卷"写下来,确认那不是 macOS 卷。

### 2. 走到 DFU 恢复 → 抹盘(真正的损失面)

DFU 恢复会清掉机器上的数据。

**缓解**:**备份是硬前置,不是"最好有"。** 而且要**验证备份能恢复**,不是"我跑过一次 Time Machine 就完了"。

### 3. 安全等级被降低 → 长期敞口

`bputil -nkcas` + `csrutil disable` 降的是这台机器的**安全基线**:

- SIP 关闭 → 系统文件可被篡改
- Secure Boot 降低 → 内核扩展无签名限制
- 日常使用就带着这套降低的基线在跑

**这是可逆的,但要你主动恢复**:

```bash
csrutil enable      # 在 1TR 或 Recovery 里跑
```

### 4. `bputil` 参数用错

参数含义搞错,改出来的 boot policy 不可预期。

**缓解**:先 `bputil --help`,读懂了再敲。手册里那句别照抄。

---

## 可逆性的诚实评估

Apple Silicon 的恢复能力强。**真正意义上的"变砖"(连 DFU 都救不回)基本不可能。**

所以风险的本质不是"机器报废",而是:

1. **丢数据**(DFU 恢复会抹盘)
2. **要花时间修**(另一台 Mac + Apple Configurator + 重装)
3. **安全等级被长期降低而忘了恢复**

第 1 条才是真正要防的。

## 两个不在步骤里、但更该注意的

### A. 降安全之后的日常使用(最容易忘)

做完 M1 之后,你面对一个**冲突**:

- 恢复 SIP → m1n1 可能起不来
- 不恢复 → 日常带着降低的安全基线用

**没有两全**,这是这条路线的固有代价。你需要明确选一个:

- **方案一**:这台机器就当实验机,接受降低的安全
- **方案二**:平时恢复 SIP,每次要玩 m1n1 时再切过去(麻烦但安全)

### B. 数据外泄 —— `~/m5-adt.plist`

原始 dump 里有:序列号、UUID、MAC 地址、`uid-aes-key`、`SEPApNonce`。

已经写进 `.gitignore`,但:

> ⚠️ `.gitignore` 只挡得住 `git add -A`,**挡不住手动 `git add -f`**。

**缓解**:外发前用脚本洗。已洗过的版本是 `~/m5-adt-topology.txt`。

## 降风险清单

### M1 之前必须满足

- [ ] M5 有**完整备份**,且**验证过能恢复**
- [ ] 第二台 Mac 可用(DFU 兜底),USB-C **数据线**确认过
- [ ] 写下:我要把 `kmutil` 装到**哪个卷**上 —— 不是 macOS 那个
- [ ] 记下当前的 boot policy(方便对比和恢复)

### M1 之后

- [ ] 记录 `bputil` / `csrutil` 到底改了什么
- [ ] 决定日常用哪套安全等级(见上面 A)

### 全程

- [ ] 外发的任何文件先洗序列号/UUID/MAC
- [ ] 每步做完回填 [PROVENANCE.md](PROVENANCE.md)

## 兜底:真把机器搞砖了

需要:**另一台 Mac** + USB-C 线 + **Apple Configurator**,把 M5 进 DFU 模式恢复。

这就是为什么 [PLAYBOOK](PLAYBOOK.md) 阶段 0 里"第二台机器"是**硬前置**,不是可选项。
